# Entre Libros — prototipo

Prototipo front-end en HTML, CSS y JavaScript.

## Abrir
Abre `index.html` en un navegador moderno. Para evitar restricciones del navegador, es preferible servir la carpeta con un servidor local (por ejemplo, la extensión Live Server de VS Code).

## Incluye
- Diseño responsive inspirado en el boceto.
- Buscador real conectado a Google Books.
- Portadas, autores, valoraciones cuando existen y descripciones proporcionadas por Google Books.
- Ficha del libro en una ventana modal.
- Accesos visuales para búsqueda por gustos, libro/frase y “Sorpréndeme”.

## Próxima fase
Para usuarios, comentarios, puntuaciones propias y listas de lectura hace falta añadir backend/base de datos y autenticación. Para recomendaciones semánticas con IA conviene añadir una llamada desde servidor (nunca exponer una clave privada en este JavaScript del navegador).
